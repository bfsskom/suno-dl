# suno-dl

Unduh lagu [Suno](https://suno.com) **publik** ke komputer Anda — file M4A + sampul.
Tanpa login, tanpa akun, portable (tanpa install).

## [⬇ Download suno-dl.exe](https://github.com/bfsskom/suno-dl/releases/latest)

Windows 8.1 / 10 / 11 · dobel-klik untuk menjalankan · tanpa install, tanpa admin.

## Cara pakai

1. Buka `suno-dl.exe`
2. Tempel tautan lagu ke kolom **Tautan lagu**, pilih folder simpan
3. Klik **Unduh** — file audio + sampul (`.jpeg`) tersimpan; klik **Buka folder** untuk melihat hasilnya

Contoh tautan yang didukung:

- `https://suno.com/s/abc123` — tautan pendek
- `https://suno.com/s/fd448325-2b8d-4934-9b11-7e7c7109223c` — tautan penuh
- `fd448325-2b8d-4934-9b11-7e7c7109223c` — UUID lagu

## Masalah umum

| Pesan di log | Penyebab / solusi |
| --- | --- |
| URL tidak valid | Pakai tautan `https://suno.com/s/...` atau UUID seperti contoh di atas |
| Tidak ada koneksi internet | Periksa WiFi/jaringan Anda lalu coba lagi |
| Lagu tidak tersedia | Lagu privat/dihapus, atau layanan Suno sedang berubah — coba tautan lain |
